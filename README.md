# Titanic Data Science Project

## About the Project

This project performs Exploratory Data Analysis (EDA)
and data visualization using the Titanic dataset.

## Technologies Used

- Python
- Pandas
- Seaborn
- Matplotlib

## Project Features

1. Dataset loading
2. Data exploration
3. Missing value analysis
4. Duplicate record analysis
5. Statistical analysis
6. Survival analysis by gender
7. Survival analysis by passenger class
8. Age distribution analysis
9. Data visualization

## Python Files

- explore.py: Performs data exploration and analysis.
- visualization.py: Creates five data visualizations.

## Dataset

Titanic dataset loaded using Seaborn.

## Installation

Clone the repository:

    git clone YOUR_GITHUB_REPOSITORY_URL

Install dependencies:

    python -m pip install -r requirements.txt

Run EDA:

    python explore.py

Run visualizations:

    python visualization.py
